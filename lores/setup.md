# GHOST HOTEL: ปูเรื่อง

*คัมภีร์ตำนาน ภาค 1: โครงเรื่อง ตัวละคร ประวัติ และเส้นเรื่อง ฉบับร่าง v0.6 (ฉากนิรันดร์ธานี)*

ชื่อทั้งหมดเป็นชื่อชั่วคราว ปีทั้งหมดเป็น พ.ศ. รายละเอียดของผีแต่ละตนอยู่ในโฟลเดอร์ [characters/](characters/)

**บอสสุดท้าย: ผีเสาเอก** เด็กสาวลูกจีนริมคลองชื่อเง็ก ถูกฝังทั้งเป็นใต้เสาเอกไม้ตะเคียนของโรงสีไฟกลางทุ่งบางแกลบในปี 2459 และถูกผูกไว้กับคำอธิษฐาน "ขอให้เรือนนี้ไม่มีวันว่าง" ปี 2533 เสาต้นนั้นถูกย้ายมาหุ้มไว้ในเสากลมต้นหนึ่งกลางล็อบบี้โรงแรมริมทะเลสาบนิรันดร์ธานี เบื้องหลังเธอคือหมอผีผู้สร้างเธอ ดู [phi-sao-ek.md](characters/phi-sao-ek.md)

## 1. เรื่องย่อในประโยคเดียว

ทายาทรุ่นสองของตระกูลผู้สร้างนิรันดร์ธานี ปฏิเสธคำแนะนำของผู้รับเหมาทุกเจ้าที่บอกให้ทุบโรงแรมร้างริมทะเลสาบทิ้ง แล้วย้ายเข้าไปคุมงานปรับปรุงให้เป็นคอมมูนิตี้ด้วยตัวเอง ผีทุกตนในโรงแรมเป็นผีที่คนไทยรู้จักดี แต่ไม่มีใครเคยถามว่า ก่อนจะกลายเป็นผี พวกเขาเคยเป็นใคร

---

## 2. เสาหลักของเรื่อง

- **ผีจริง คนจริง** ผีทุกตนเป็นผีตามความเชื่อจริง (กระสือ เปรต กระหัง ผีแม่ม่าย กุมารทอง) แต่ทุกตนเคยเป็นคนที่เหตุการณ์ในชีวิตผลักให้กลายเป็นผีชนิดนั้น ผู้เล่นรู้จัก "ผี" ก่อน แล้วค่อยได้รู้จัก "คน"
- **ร่วมสมัย** เรื่องของผีแต่ละตนสะท้อนประเด็นที่คนวันนี้เข้าใจ: ภาพไวรัล แรงงานข้ามชาติ นายหน้าหลอก หนี้ ฟองสบู่อสังหาฯ ข่าวลือ และการทำความเชื่อให้เป็นสินค้า
- **เมืองที่ไม่มีวันว่าง** นิรันดร์ธานี (เมืองสมมติ) ถูกสร้างบนสัญญาว่าจะเป็นเมืองใหม่ที่ผู้คนเต็มไปหมด แล้ววิกฤตปี 2540 ทำให้กลายเป็นเมืองตึกร้าง คำอธิษฐานของเสาคือคำสัญญาเดียวกันในรูปของคำสาป
- **เก็บเรื่อง ไม่ใช่เก็บคน** ธามเป็นคนที่อยากเก็บทุกอย่างไว้ ทั้งตึก เสา และของเก่า เสาก็อยากเก็บทุกคนไว้เหมือนกัน เส้นเรื่องของเขาคือการเรียนรู้ว่าอะไรควรเก็บ และอะไรต้องปล่อย
- **ปรับปรุงคือการสืบสวน** ทุกโซนของโรงแรมที่ถูกปรับปรุงเปิดตำนานของผีหนึ่งตน ทุกปริศนาที่แก้ได้คืนชิ้นส่วนชีวิตของผีตนนั้น
- **ผูกมิตร ไม่ใช่ขับไล่** ผู้เล่นไม่เคยเอาชนะผี แต่ "จำ" พวกเขาได้
- **ชื่อคือทุกสิ่ง** เหยื่อถูกเลือกจากชื่อ ผีทุกตนถูกคนอื่นตั้งชื่อใหม่เพื่อใช้พวกเขา (ชื่อบนผ้ายันต์ ชื่อบนเวที ชื่อสินค้า) การเอ่ยชื่อจริงทำให้เป็นอิสระ แม้แต่ธามก็เป็นที่รู้จักในนาม "ลูกเจ้าของเมือง" มากกว่าชื่อตัวเอง
- **ชานกรุงหลายภาษา** ผีแต่ละตนพูดภาษาของตัวเอง: ไทยกลาง จีนแต้จิ๋ว อีสาน อังกฤษ เหมือนชานกรุงที่คนจากทุกที่มารวมกัน
- **กลับบ้าน** ธามเป็นลูกหลานจีนที่โตมาในโรงเรียนนานาชาติ อ่านภาษาจีนไม่ออก การเรียนอักษรจีนทีละตัวคือกุญแจของตอนจบ
- **จากเรือนที่ต้องเต็ม สู่ลานที่ใครก็มาแล้วกลับบ้านได้** โรงแรมต้องการให้คนมาแล้วอยู่ คอมมูนิตี้ต้องการให้คนมาแล้วกลับบ้านพร้อมความทรงจำ
- **มีมุกเดียวที่รอด** ตอนจบขมปนหวาน แล้วถูกหักมุมด้วยผีตนหนึ่งที่ไม่ยอมไป

## 3. ฉาก

**โรงแรมเวสต์เลค แกรนด์ (The Westlake Grand)** ริมทะเลสาบนิรันดร์ธานี เมืองใหม่ชานกรุงฝั่งนนทบุรี (โรงแรมและเมืองสมมติ)

*ชื่อเมือง ชื่อโรงแรม ตระกูลเจ้าของ บริษัทผู้พัฒนา ร้านค้า และเหตุการณ์ทั้งหมดเป็นเรื่องแต่ง รูปทรงอาคาร ทำเล และเรื่องการปรับปรุงตึกร้างเป็นคอมมูนิตี้ ล้อมาจากเมืองใหม่และโรงแรมร้างริมทะเลสาบที่มีอยู่จริงในนนทบุรี ดูหัวข้อ 14*

**ที่มาของชื่อ:** คุณสุเมธตั้งชื่อเมืองใหม่ตามโรงสีไฟนิรันดร์ของทวด เป็น **นิรันดร์ธานี** เมืองที่จะไม่มีวันว่าง โดยไม่รู้ว่ากำลังยกคำอธิษฐานของเสาไปใส่ทั้งเมือง แต่กับโรงแรม เขาบอกว่าตึกทรงฝรั่งในเมืองแห่งอนาคตต้องมีชื่อฝรั่ง ป้ายหน้าโรงแรมจึงเขียนแต่ภาษาอังกฤษ มีแค่ป้ายไม้เก่าหลังเคาน์เตอร์ที่ย่าพลอยเก็บมาจากโรงสีตอนรื้อ เขียนว่า **"โรงสีไฟนิรันดร์ 2459"** ผู้เล่นที่อ่านเจอจะรู้ก่อนใครว่าโรงแรมกับโรงสีคือเรือนเดียวกัน

**ก่อนมีเมือง**
- ที่ดินผืนนี้เคยเป็น **ทุ่งนาบางแกลบ** (ย่านสมมติ ตั้งชื่อตามแกลบที่ลอยเต็มคลองหน้าโรงสี) มีคลองซอยต่อออกเจ้าพระยา กลางทุ่งมี **โรงสีไฟนิรันดร์** ของ **หลวงไพศาลพาณิชย์** พ่อค้าจีนสยามผู้ได้บรรดาศักดิ์ สร้างปี 2459 มีปล่องโรงสีสูง ยุ้งฉาง และเรือข้าวจอดเรียงริมคลอง
- ใต้ **เสาเอกไม้ตะเคียน** ของโรงสีคือหลุมที่เง็กถูกฝัง
- ปี 2498 **มั่น** น้องชายของเง็ก ซื้อโรงสีและทุ่งรอบๆ ทุ่งผืนนี้กลายเป็นที่ดินของตระกูล
- ปี 2533 ตระกูลขุดทุ่งเป็น **ทะเลสาบ** เอาดินไปถมยกระดับเมืองใหม่ โรงสีถูกรื้อ จุดที่โรงสีเคยตั้งอยู่ตอนนี้อยู่ใต้น้ำกลางทะเลสาบ

**ตัวโรงแรม**
- อาคารแบบ modern classic ยุคนิรันดร์ธานีบูม ระเบียงห้องพักยื่นเป็นเส้นโค้งซ้อนกันเป็นชั้นเหมือนคลื่นน้ำ มีปีกห้องพักรายวันและปีกเซอร์วิสอพาร์ตเมนต์ ราว 112 ห้อง
- ล็อบบี้ชั้นล่างโปร่ง เพดานสูง ลมพัดผ่านได้ทั้งโถงจนนั่งได้โดยไม่ต้องเปิดแอร์ มีมุขรถเทียบหน้าขนาดใหญ่ และ **เสากลมขนาดใหญ่** เรียงกันแบบไม่สมมาตร เสาต้นที่ผิดแถวคือเสาที่หุ้มเสาตะเคียนไว้ข้างใน จับแล้วชื้นนิดๆ อยู่เสมอ ทั้งที่เป็นคอนกรีต
- สระว่ายน้ำหลังอาคาร ห้องจัดเลี้ยง ห้องใต้ดินที่น้ำจากทะเลสาบซึมเข้าทุกหน้าฝน และวิวพระอาทิตย์ขึ้นกับตกเหนือทะเลสาบ

**ยุคสมัยของโรงแรม:**

| ยุค | สภาพโรงแรม |
|---|---|
| 2536-2539 | ยุคบูม นักธุรกิจ วิศวกร และครอบครัวที่ย้ายมาอยู่เมืองใหม่ แคมป์คนงานก่อสร้างรอบทะเลสาบ |
| 2540-2544 | วิกฤตต้มยำกุ้ง ตึกรอบทะเลสาบสร้างค้าง โรงแรมให้เช่าห้องจัดเลี้ยงจัดหมอลำคืนวันเสาร์ และให้นายหน้าส่งคนไปต่างประเทศเช่าห้อง คืนเดียวที่เต็มคือช่วงเอเชียนเกมส์ ธันวาคม 2541 |
| 2545-2552 | ประคองตัวกลางเมืองที่ครึ่งหนึ่งยังว่าง แขกน้อยแต่ไม่เคยเจ๊ง จนคนในย่านสงสัย |
| 28 ธ.ค. 2552 | ปิดร้าง |
| 2553-2568 | ตึกร้างริมทะเลสาบ เป้าของสายล่าผี นักถ่ายรูปตึกร้าง และยูทูบเบอร์ บริษัทของตระกูลขอทุบหลายครั้ง ย่าพลอยไม่ยอมทุกครั้ง |
| 2569 | ธามรับมรดก เริ่มปรับปรุง |

- **ปี 2568** รถไฟฟ้าโมโนเรลสายใหม่เข้านิรันดร์ธานี คนดูคอนเสิร์ตและคนมางานที่ศูนย์แสดงสินค้าล้นย่าน แต่มาเฉพาะวันที่มีงานใหญ่ วันธรรมดาริมทะเลสาบยังเงียบ
- นาฬิกาแขวนหลังเคาน์เตอร์หยุดที่ **03:07** นาทีที่เด็กสาวถูกฝังเมื่อร้อยสิบปีก่อน
- **ตำนานในย่าน:** คนวิ่งรอบทะเลสาบตอนค่ำรู้กันว่า ถ้าได้ยินใครเรียกชื่อจากฝั่งโรงแรมร้างหลังมืด อย่าขานรับ บางคืนมีไฟเปิดอยู่ชั้นบนทั้งที่ตึกไม่มีไฟฟ้า

**ปัจจุบัน** หน้าฝน น้ำทะเลสาบเอ่อ ระบบไฟและน้ำของตึกตายหมด สัญญาณมือถือในตึกแย่มาก ที่เดียวที่ชัดคือดาดฟ้า

**ทำไมไม่ทุบทิ้ง:** ผู้รับเหมาทุกเจ้าบอกให้ทุบแล้วสร้างใหม่ เพดานต่ำ ห้องพักน้อย ระบบเสื่อมหมด ธามตอบว่า *"ถ้าจะสร้างใหม่ นิรันดร์ธานียังมีที่ว่างอีกเยอะ ไม่จำเป็นต้องทุบตึกที่ย่าเฝ้ามาทั้งชีวิต แล้วผมก็ชอบตึกนี้"*

**ทำไมไม่หนีไป:** พินัยกรรมของย่าพลอยยกตึกให้ธาม ห้ามขายจนกว่าจะพ้นทำบุญร้อยวัน บอร์ดของบริษัทให้เวลาเขาจนถึงวันเปิดลาน ถ้าไม่มีคนมา ตึกจะถูกขายให้บริษัทแล้วทุบ ธามย้ายเข้าไปนอนในห้องชุดเจ้าของเพื่อคุมงานเอง เพราะเขาไม่เชื่อเรื่องผี และเพราะเขาอยากพิสูจน์ว่าเขาไม่ได้เป็นแค่ลูกเจ้าของเมืองที่เล่นของเล่นราคาแพง

## 4. ตัวละครหลัก

### ธาม (พระเอก ตัวละครหลักที่ผู้เล่นควบคุม)
- อายุ 35 **ทายาทรุ่นสองของตระกูลผู้สร้างนิรันดร์ธานี** โตมาในโรงเรียนนานาชาติ เรียนสถาปัตย์ที่ต่างประเทศ กลับมาทำงานในบริษัทของพ่อโดยไม่มีใครจำชื่อเขาได้ นอกจาก "ลูกคุณสุเมธ"
- พูดเบา ใจเย็น ชอบตึกเก่าและของเก่าแบบที่คนอื่นมองว่าเป็นขยะ พูดประโยคแบบ *"ไม่จำเป็นต้องมีแผนธุรกิจสำหรับทุกอย่าง"* จนบอร์ดปวดหัว
- **ไม่เชื่อเรื่องผี** ประโยคประจำตอนต้นเกม: *"ถ้าไปเดินในโรงพยาบาลตอนสองทุ่ม กับมาเดินที่นี่ตอนสองทุ่ม คุณกลัวที่ไหนมากกว่ากัน"* เกมจะตอบคำถามนี้ให้เขาเอง
- เป็นพ่อเลี้ยงเดี่ยว มีลูกสาววัย 6 ขวบชื่อ **ข้าวหอม** อยู่กับเขาทุกสุดสัปดาห์ เหตุผลที่เขาอยากทำลานนี้: *"วันหนึ่งลูกโตขึ้น เขาจะเล่าให้ลูกของเขาฟังว่า เคยมาที่นี่ตอนเด็ก มากับป๊า"*
- **สมุดสเก็ตช์สถาปัตย์** คือบันทึก แผนผังการปรับปรุง แผนที่ และ **สมุดอักษรจีน** ที่ค่อยๆ เพิ่มขึ้นตลอดเกม **โทรศัพท์** ของเขาคือไฟฉาย กล้อง และแอปจัดการโปรเจกต์ที่ผีเริ่มส่งข้อความเข้ามา
- เคยมาครั้งเดียวตอนอายุ 8 ขวบ ปี 2542 ตอนโรงแรมยังเปิด จำได้แค่ประโยคเดียวของย่าพลอย: *"ถ้าใครเรียกชื่อหนูตอนกลางคืนที่นี่ อย่าขานนะ ต่อให้เสียงเหมือนย่าก็ตาม"*
- เขาคือ **เจ้าของ** และเป็น **เหลนของมั่น** จึงเป็นญาติทางสายเลือดของเง็ก โดยที่เขาไม่รู้
- **ข้อบกพร่อง:** อยากเก็บทุกอย่างไว้ วิศวกรบอกให้รื้อเสากลมต้นที่ผิดแถวเพื่อเปิดผังโถง เขาไม่ยอม เสาต้นนั้นชอบเขามาก

### พิมกับต้น (คู่รักตัวละครสมทบ ผู้เช่าร้านแรกของลาน)
- **พิม** อายุ 31 อดีตนักออกแบบตกแต่งภายในที่ถูกเลิกจ้าง **ต้น** อายุ 33 อดีตผู้ก่อตั้งสตาร์ทอัพที่แอปเจ๊งและทิ้งหนี้ไว้ ทั้งคู่ถูกค่าครองชีพไล่ออกจากคอนโด
- เห็นประกาศรับสมัครร้านค้าของลาน เอาเงินก้อนสุดท้ายมาลงกับร้านเครื่องดื่มเล็กๆ ริมทะเลสาบ ไม่มีที่อยู่ ธามจึงให้อยู่ห้องพักพนักงานเก่าระหว่างปรับปรุง แลกกับให้พิมช่วยออกแบบพื้นที่
- **ห่วงของต้น:** หนี้จริงมากกว่าที่บอกพิมถึงสามเท่า และเขาแอบสมัครงานต่างประเทศผ่านนายหน้าโดยไม่บอกพิม เหมือนทิดคำเมื่อ 29 ปีก่อน
- **เส้นเรื่องของทั้งคู่:** เริ่มจากโทษกันเรื่องเงิน จบด้วยการพูดความจริง ทิดคำกับลำดวนคือคู่รักที่ถูกหนี้และความลับพรากจากกัน และเป็นกระจกของพิมกับต้น ธามเป็นคนที่เห็นเรื่องนี้ก่อนทั้งคู่

## 5. ตระกูลและคนสำคัญในย่าน

### ผังตระกูล
| รุ่น | คน | บทบาท |
|---|---|---|
| ทวดของธาม | **มั่น** (2449-2532) | เด็กที่ไม่ได้ขานรับ ซื้อโรงสีปี 2498 ถวายข้าวต้มที่เสาทุกเช้า |
| ปู่ | **อากงเสถียร** (2475-2548) | ลูกชายของมั่น ค้าข้าว เก็บทุ่งไว้เป็นที่ดินของตระกูล |
| ย่า (ศักดิ์) | **ย่าพลอย** (2483-2569) | ลูกสาวของมั่น น้องสาวของอากง ได้ที่ดินผืนโรงสีเป็นมรดก เจ้าของและผู้บริหารโรงแรม |
| พ่อ | **คุณสุเมธ** (เกิด 2500) | ผู้สร้างนิรันดร์ธานีบนทุ่งของตระกูล ประธานบริษัท |
| รุ่นสอง | **ธาม** (เกิด 2534) | ทายาทรุ่นสอง ผู้เล่น |
| ลูก | **ข้าวหอม** (เกิด 2563) | ลูกสาวของธาม |

### ย่าพลอย
- เกิดปี 2483 **ลูกสาวของมั่น** ธามเรียกว่าย่า คนในย่านเรียกว่าป้าพลอยหรือเจ๊พลอย
- ปี 2532 พ่อเสียชีวิต ก่อนตายพ่อให้สัญญาข้อเดียว: **"อย่าทิ้งเสาต้นนั้น"** โดยไม่บอกเหตุผล
- ปี 2533 หลานชาย (คุณสุเมธ) จะขุดทุ่งทำทะเลสาบ ย่าพลอยยอมให้ที่ดินผืนโรงสีสร้างโรงแรม โดยยื่นเงื่อนไขข้อเดียว: **ย้ายเสาตะเคียนของโรงสีมาไว้ในล็อบบี้ ทั้งตอทั้งดินหลุมเสา** และเธอต้องเป็นคนบริหารโรงแรม
- เธอถวายข้าวต้มที่เสาทุกเช้าตามที่พ่อเคยทำ โดยไม่รู้ว่ากำลังเลี้ยงอะไร
- หลังวิกฤตปี 2540 บริษัทของหลานจมหนี้ ย่าพลอยขายทรัพย์สินส่วนตัวซื้อโรงแรมไว้ทั้งหมด
- ปี 2552 พบว่าผู้จัดการแอบเลี้ยงกุมารทองไว้ในโรงแรม และพบสมุดบันทึกที่พ่อซ่อนไว้ในหีบการบูร เธอไล่ผู้จัดการออก **หยุดถวายของ ปิดโรงแรม และปล่อยให้ผีเฝ้าหลับ** อยู่ 17 ปี ไม่ยอมขาย ไม่ยอมให้ทุบ
- เสียชีวิตต้นปีนี้ อายุ 86 อย่างสงบ เสาจึงเก็บเธอไว้ไม่ได้
- **จดหมายแนบพินัยกรรมถึงธาม:** *"ถ้าพ้นร้อยวันแล้วอยากทุบก็ทุบไปเถอะ แต่ย่ารู้ว่าหนูไม่ทุบหรอก ระหว่างนี้อย่านอนที่นั่น"*
- **ม้วนเทปคาสเซ็ต** ซ่อนไว้ทั่วโรงแรม อัดตั้งแต่ปี 2552 ถึง 2568 เป็นเนื้อเรื่องแบบเก็บสะสม ม้วนแรกขึ้นต้นว่า: *"ถ้าหนูกำลังฟังอยู่ แปลว่าหนูนอนที่นี่แล้ว ย่าบอกแล้วว่าอย่า งั้นฟังให้ดีนะ"*
- **ทำไมเธอทำให้จบไม่ได้:**
  1. ผีเฝ้าจะปรากฏตัวก็ต่อเมื่อเรือนเต็ม และย่าพลอยทำใจเอาคนไปเสี่ยงไม่ได้
  2. พ่อของเธอเรียกพี่สาวว่า **"เจ๊"** มาตลอด ย่าพลอยไหว้ป้ายบรรพบุรุษที่มีชื่อ 玉 มาทั้งชีวิต แต่ไม่เคยรู้ว่าเป็นใคร
  3. เธอเป็นคนย้ายเสามาเอง ความรู้สึกผิดทำให้เธอไม่กล้าเข้าใกล้มันอีก

### คุณสุเมธ
- พ่อของธาม อายุ 69 สร้างเมืองใหม่บนทุ่งของตระกูลตั้งแต่ปี 2532 เห็นเมืองรุ่ง ร้าง และค่อยๆ ฟื้น
- เชื่อตัวเลข ไม่เชื่อผี ในบอร์ดเขาไม่ค้านลูกตรงๆ แต่ก็ไม่ช่วย ในองก์ 3 เผยว่าเขารู้มาตลอดว่ามีอะไรบางอย่างที่เสาต้นนั้น เพราะเคยเห็นย่าพลอยวางข้าวต้ม และเพราะเมืองของเขาไม่เคยเต็มสักที

### น้อย
- อายุ 30 ขายข้าวมันไก่รถเข็นหน้าคอนโดริมทะเลสาบ ส่งข้าวให้ย่าพลอยมาสิบปี และเป็นคนยื่นกุญแจให้ธาม เป็นผู้เช่ารายที่สองของลาน
- โตมากับยาย ได้ยินมาตลอดว่าแม่ "หนีไปกับผู้ชาย" ตั้งแต่เธอยังไม่ถึงสองขวบ
- **ความลับที่เธอเองก็ไม่รู้:** เธอคือลูกสาวของสีดา (กระสือ) ดู [sida.md](characters/sida.md)

### คุณวิชัย
- อายุ 70 กว่า อดีตผู้จัดการโรงแรม **ยังมีชีวิตอยู่** เปิดแผงพระเครื่องย่านท่าพระจันทร์
- เป็นคนทำให้น้องฟ้ากลายเป็นกุมารทอง ดู [nong-fah.md](characters/nong-fah.md)

### บ้านใหญ่
- บ้านเก่าของตระกูลริมเจ้าพระยาที่บางแกลบ คุณสุเมธยังอยู่ที่นี่ มีโต๊ะบูชาบรรพบุรุษที่มั่นตั้งไว้ บนนั้นมีป้ายชื่อเขียนอักษร 玉 ที่ไม่มีใครในบ้านรู้ว่าเป็นใคร
- ฉากที่บ้านใหญ่ในองก์ 3 คือฉากเฉลยชื่อบอส

## 8. วงจรของแต่ละบท

แต่ละบทผูกกับ **โซนปรับปรุง** หนึ่งโซน ธามปรับปรุงเฉพาะที่จำเป็น เก็บของเดิมไว้ให้มากที่สุด ของเดิมทุกชิ้นที่เก็บไว้มีเรื่องเล่า

| บท | โซนปรับปรุง | งาน |
|---|---|---|
| 1 | ล็อบบี้ เคาน์เตอร์ สระว่ายน้ำ | ทำความสะอาดเฟอร์นิเจอร์เดิม สูบน้ำสระทิ้ง เตรียมทำสวน |
| 2 | ดาดฟ้า ระบบไฟ ระบบน้ำ | เดินไฟใหม่ เปลี่ยนท่อ ห้องเครื่องลิฟต์ |
| 3 | ห้องจัดเลี้ยง ระเบียงโค้ง | ซ่อมเวที เก็บระเบียงเดิม |
| 4 | ห้องใต้ดิน ห้องผู้จัดการ ปีกอพาร์ตเมนต์ | สูบน้ำ ห้องน้ำใหม่ เคลียร์ของเก่า |

1. **สัญญาณ** มีบางอย่างผิดปกติในโซนที่กำลังปรับปรุง ช่างไม่ยอมทำงานหลังมืด
2. **เผชิญหน้า** ผีปรากฏตัวในร่างที่ทุกคนรู้จักจากตำนาน มีฉากไล่ล่าหรือตุ้งแช่
3. **สืบสวน** ปริศนาสามข้อ แต่ละข้อคืนชิ้นส่วนชีวิตของ "คน" ที่อยู่หลังผี
4. **ชื่อ** ผู้เล่นได้ชื่อจริงคืน สายสิญจน์หย่อนลง
5. **ผูกมิตร** ฉากเงียบๆ แล้วผีมอบพลังให้ งานในโซนนั้นเดินต่อได้
6. **เอาคืน** ผีเฝ้าโต้กลับ มีห้องใหม่โผล่มา มีข้าวต้มถ้วยใหม่ที่เสา และมีคนลงทะเบียนงานเปิดลานเพิ่มในแอปของธาม

**กฎจังหวะ:** หลังฉากผูกมิตรทุกครั้ง ความสยองครั้งต่อไปต้องมาเร็วขึ้นและแรงขึ้น

**ปริศนาร่วม: สมุดอักษรจีน** ทุกบทสอนธามอักษรจีนอย่างน้อยหนึ่งตัว (ตัวเลขจีนจากบัญชีโรงสี, 興 จากจดหมายอาเฮง, อักษรบนป้ายศาลเจ้าในภาพถ่ายของวอลต์ ฯลฯ) ในองก์ 3 ธามกลับไปบ้านใหญ่ และอ่านป้ายบรรพบุรุษออกเป็นครั้งแรก: **玉 เง็ก**

## 9. เส้นเรื่อง

### บทนำ: รับมรดก
ห้องประชุมบอร์ด ผู้รับเหมาสามเจ้าเสนอแผนทุบ ธามปิดแฟ้มแล้วพูดว่าจะเก็บตึกไว้ คืนนั้นเขาขับรถไปที่ทะเลสาบท่ามกลางสายฝน รถไฟฟ้าโมโนเรลสายใหม่แล่นผ่านเหนือหัว ที่ประตูรั้ว **น้อย** ยื่นกุญแจให้: *"ย่าพลอยสั่งไว้ว่าอย่านอนที่นี่ แล้วถ้าใครเรียก อย่าขานนะคะ"* ธามยิ้ม แล้วถามเธอว่าอยากเช่าร้านไหม ตอน 03:07 นาฬิกาที่หยุดเดินตีขึ้นหนึ่งครั้ง และมีเสียงหวูดโรงสีดังมาจากกลางทะเลสาบ ที่ที่ไม่มีโรงสีมาสามสิบกว่าปีแล้ว

### องก์ 1: ปลุกตึก
- ธามเดินสำรวจกับช่าง ถ่ายรูปทุกมุมลงสมุด ในรูปมีสิ่งที่ไม่ได้อยู่ตรงนั้น
- เขาเปิดรับสมัครร้านค้า **ไม่กี่นาทีใบสมัครก็เริ่มเข้ามา** จากบัญชีที่ไม่มีรูปโปรไฟล์และชื่อสะกดแบบโบราณ ใบแรกสุดคือ "ร้านข้าวต้ม" ลงวันที่ปี 2459
- ทุกเช้ามีข้าวต้มถ้วยเล็กกับธูปสามดอกที่เสากลมต้นที่ผิดแถวในล็อบบี้ ไม่มีใครเอามาวาง
- พิมกับต้นมาสมัครเป็นร้านแรกและย้ายเข้ามาอยู่ห้องพักพนักงาน
- ทุกคนเจอลุงเฉลิม ซึ่งดูเหมือนคนเฝ้าตึก ธามรู้ว่าเขาตายแล้วตอนไฟติดแล้วเขาไม่มีเงา
- ธามเจอเทปม้วนแรกของย่าพลอย และคลิปในมือถือที่สายล่าผีทำหล่นไว้
- **บท 1: สีดา (กระสือ)**
- **จบองก์:** งานทดลองเปิดลานครั้งแรก ตลาดของวินเทจริมทะเลสาบ คนมาเต็มโถงล็อบบี้ ข้าวหอมวิ่งเล่นระหว่างเสากลม คืนนั้นเรือน "เต็ม" เป็นครั้งแรกตั้งแต่ปี 2552 บางอย่างใต้พื้นล็อบบี้สูดหายใจเข้า

### องก์ 2: เสียงเรียก
- **บท 2: อาเฮง (เปรต)** ภาพความทรงจำของอาเฮงเผยว่ามีเด็กสาวถูกฝังใต้เสาของโรงสีกลางทุ่ง และเสาต้นนั้นคือเสาในล็อบบี้
- ตอนกลางคืนมีเสียงเรียกชื่อไปตามทางเดินด้วยเสียงที่คุ้นเคย ผีพูดโดยมีเสียงเด็กสาวซ้อนอยู่ข้างใต้ เธอเรียกธามว่า **"เจ้าของ"**
- **ข้อเสนอ:** ถวายของ ต่อคำอธิษฐาน แล้วลานนี้จะมีคนเต็มทุกวัน บอร์ดจะเงียบ และทุกคนที่ธามรักจะปลอดภัย
- ทุกอย่างราบรื่นจนน่าสงสัย ผู้รับเหมาที่ทิ้งงานกลับมาเอง ยอดลงทะเบียนงานพุ่ง
- **เริ่มบท 3: ทิดคำกับลำดวน** ต้นต้องทาเล็บแดง
- **การทะเลาะ:** พิมเจอใบแจ้งหนี้จริงของต้น และสัญญานายหน้าส่งคนไปทำงานต่างประเทศที่เขาซ่อนไว้ ทั้งคู่ทะเลาะกันกลางลาน ธามได้ยินทั้งหมด และเสาก็ฟังอยู่

### องก์ 3: ขานรับ
- ดึกคืนหนึ่ง ต้นได้ยินพิมเรียกชื่อเขาจากล็อบบี้ **เขาขานรับ** แล้วหลับไม่ตื่น ขวัญของเขาถูกเอาไป
- คนในย่านบอกว่าเป็นฝีมือผีแม่ม่าย พิมเกือบเชื่อ จนจบบท 3 และรู้ว่าลำดวนพยายามเตือนต้นมาตลอด
- ช่วง **เล่นเป็นต้น** เกิดขึ้นใน "อีกด้าน" ของโรงแรม โรงแรมเวอร์ชันมืดที่ครึ่งหนึ่งเป็นโรงสีไม้เก่า เต็มไปด้วยสายสิญจน์ดำ นอกหน้าต่างไม่มีทะเลสาบ มีแต่ทุ่งนาในความมืด ขวัญของเขาพยายามจำชื่อตัวเองให้ได้
- **บท 4: น้องฟ้า (กุมารทอง)** รวมฉากไปเผชิญหน้าคุณวิชัยที่ท่าพระจันทร์ น้องฟ้าเรียกธามว่า "ป๊า" เพราะได้ยินข้าวหอมเรียก
- ผีเฝ้าปรากฏร่าง: เด็กสาวร่างสูงผิดสัดส่วนในเสื้อคอจีน ผิวเป็นลายเสี้ยนไม้ตะเคียน ผ้ายันต์ตอกปิดหน้าเขียนว่า **"มั่น"**
- **ฉากบ้านใหญ่:** ธามขับรถไปบ้านเก่าริมเจ้าพระยากลางดึก พ่อยังไม่นอน ทั้งคู่ยืนหน้าโต๊ะบูชา ธามอ่านป้ายบรรพบุรุษออก: **玉 เง็ก** เด็กสาวที่ขานรับแทนน้อง คือพี่สาวของทวด ผีเฝ้าคือญาติของเขาเอง คุณสุเมธพูดขึ้นเป็นครั้งแรกว่าเขาเห็นย่าพลอยวางข้าวต้มที่เสาทุกเช้ามาตลอด
- น้องฟ้าพาลงไป

### ฉากสุดท้าย: หลุมเสา (คืนสารทจีน)
รายละเอียดอยู่ใน [phi-sao-ek.md](characters/phi-sao-ek.md) หัวข้อ 7
- **เฟส 1: สายสิญจน์** แสงของสีดาเผยให้เห็นสายสิญจน์ น้องฟ้ากระซิบเตือน
- **เฟส 2: เสียงเรียก** อย่าขาน แม้เป็นเสียงข้าวหอมเรียก "ป๊า" ลำดวนลำกลบเสียงเรียก ต้นพูดความลับออกมาเอง ทิดคำบินลงไปรับขวัญของเขา
- **เฟส 3: เง็ก** อาเฮงรัดร่างผีเฝ้าไว้ ธามกระชากผ้าออก: *"เจ๊เง็ก"* เด็กสาวอายุ 16 ยืนอยู่ในโคลน มองหาน้องชาย ธาม: *"มั่นไม่อยู่แล้วนะครับ แต่ทวดไม่เคยลืมเจ๊เลยสักวัน"*
- **เฟส 4: อาจารย์ดำ** อาเฮงบอกคำอธิษฐานเดิม ธามถอนคำ: *"เรือนนี้ว่างได้แล้ว"* หมอผีถูกขังในหม้อดินและถ่วงเจ้าพระยาที่ท่าน้ำบางแกลบ ลุงเฉลิมกดกระดิ่ง

### บทส่งท้าย: เช็กเอาต์
- รุ่งเช้า อาเฮงขุดกระดูกของเง็กขึ้นจากดินหลุมเสาใต้ล็อบบี้
- พระจากวัดริมเจ้าพระยามาสวด และ **ล้อมโรงแรมด้วยสายสิญจน์ขาว**
- เง็กได้รับการฌาปนกิจ ป้าย 玉 ถูกวางกลับบนโต๊ะบูชาบ้านใหญ่ คราวนี้ทุกคนรู้ว่าเธอคือใคร
- ทุกคนกรวดน้ำ ผีบอกลาทีละตนแล้วไปผุดไปเกิด เง็กไปเป็นคนสุดท้าย *ตัวเลือก:* ที่ขอบแสงมีชายแก่คนหนึ่งยืนรอ
- เสาตะเคียนแตกกลางลำ คอนกรีตที่หุ้มไว้ร้าวเป็นเส้นเดียวจากพื้นถึงเพดาน ห้องส่วนเกินหายไป ธามปล่อยให้มันแตก เป็นครั้งแรกที่เขาไม่พยายามเก็บอะไรไว้

### บทส่งท้าย: เปิดลาน (หกเดือนต่อมา)
ธามตัดสินใจ **ไม่เปิดเป็นโรงแรมอีก** ห้องพักชั้นบนปล่อยว่างไว้ เพราะเรือนนี้ไม่ต้องเต็มอีกแล้ว ชั้นล่างทั้งชั้นเปิดโล่งเป็น **คอมมูนิตี้ริมทะเลสาบ** ชื่อ **"ลานหยก"** ตามความหมายของชื่อ 玉 มีร้านอาหารและเครื่องดื่มให้คนในย่านมานั่งจนค่ำ แล้วกลับบ้าน

- ปรับปรุงเฉพาะที่จำเป็น: ห้องน้ำ ท่อ และไฟใหม่หมด ส่วนเสากลม ระเบียงโค้ง ผนังคอนกรีต และเฟอร์นิเจอร์เดิมที่ขัดสะอาดแล้ว เก็บไว้เกือบทั้งหมด โถงเปิดโล่งให้ลมผ่าน นั่งได้โดยไม่ต้องเปิดแอร์
- ร้านในลานคัดจากคนในย่านและวัตถุดิบไทยจากแต่ละภาค **ร้านสมมติทั้งหมด ไม่ใช้ชื่อร้านจริง** แต่ละที่มีเงาของผีหนึ่งตน:
  - **ร้านเครื่องดื่มริมทะเลสาบของพิมกับต้น** ร้านแรกของลาน ต้นทำบัญชีให้พิมดูทุกเดือน
  - **ร้านข้าวมันไก่ของน้อย** ย้ายจากรถเข็นมาเปิดหน้าลาน ข้างสวนที่พบกระดูกของแม่
  - **คาเฟ่ในล็อบบี้** เคาน์เตอร์ต้อนรับเดิมกลายเป็นเคาน์เตอร์กาแฟ กระดิ่งทองเหลืองของลุงเฉลิมและป้ายไม้ "โรงสีไฟนิรันดร์ 2459" แขวนอยู่ที่เดิม
  - **เวทีหมอลำคืนวันเสาร์** ในห้องจัดเลี้ยงเดิม
  - **สวนในสระ** สระว่ายน้ำเก่าถมเป็นสวนต่ำ ตรงจุดที่พบกระดูกของสีดามีต้นลำดวนหนึ่งต้น
  - **ตู้ถ่ายรูปฟิล์ม** กับผนังภาพเก่าของโรงสี โรงแรม และทุ่งนาบางแกลบ
- ลานใช้เป็น "ห้องทดลอง" ของย่าน สำหรับงานเล็กที่ศูนย์แสดงสินค้าใหญ่จัดไม่ได้: ตลาดของวินเทจ วันของสัตว์เลี้ยง สงกรานต์ และลานสเกตบอร์ด
- เสากลมต้นที่ร้าวถูกเก็บไว้กลางลาน มีป้ายเล็กเล่าเรื่องเด็กสาวชื่อเง็ก ไม่มีใครถวายข้าวต้มอีก แต่มีคนแวะมาอ่านทุกวัน
- ช็อตสุดท้าย: พระอาทิตย์ตกเหนือทะเลสาบ ร้านเริ่มปิด คนทยอยเดินกลับบ้าน ลานว่างลงอย่างสงบ ธามจูงมือข้าวหอมเดินออกทางมุขรถเทียบ ข้าวหอมถามว่าพรุ่งนี้มาอีกได้ไหม

## 12. เครื่องมือความสยอง

- **อย่าขาน** เสียงเรียกชื่อด้วยเสียงคนที่ไว้ใจ ในช่วงท้ายรวมถึงเสียงข้าวหอมเรียก "ป๊า" ขานผิดจังหวะจะเจอตุ้งแช่ หรือเกมโอเวอร์
- **แอปโปรเจกต์** ใบสมัครร้านค้าและการลงทะเบียนงานจากคนที่ตายแล้ว: *"คืนนี้ถึงนะคะ เปิดประตูทิ้งไว้ด้วย"*
- **ช่างไม่ยอมอยู่หลังมืด** งานที่ทำค้างไว้ตอนเย็นเสร็จเองตอนเช้า หรือถูกรื้อกลับ
- **หวูดโรงสี** เสียงหวูดเรียกคนงานดังจากกลางทะเลสาบตอน 03:07 ทั้งที่โรงสีถูกรื้อไปตั้งแต่ปี 2533
- **ทุ่งนาในกระจก** ตอนผีเฝ้าอยู่ใกล้ กระจกบานที่มองออกไปทะเลสาบสะท้อนเป็นทุ่งนากลางคืน มีปล่องโรงสีตั้งอยู่ไกลๆ
- **คลิปสายล่าผี** มือถือที่ตกอยู่ตามห้อง ในคลิปมีคนเดินตามหลังคนถือกล้องมาตลอด
- **แสงเขียวลอยเหนือสระ** (สีดา)

## 13. แผนลงพื้นที่ (รวม)

รวมจากหัวข้อ "สิ่งที่ต้องไปค้นคว้า" ในไฟล์ตัวละครทุกไฟล์ จัดตามสถานที่ ส่วนใหญ่อยู่ในย่านที่ทีมอาศัยอยู่ เดินได้ในวันเดียว

| สถานที่ | ใช้กับ |
|---|---|
| อาคารโรงแรมเดิมริมทะเลสาบ (ปัจจุบันเปิดเป็นคอมมูนิตี้) | ฉากหลัก เสากลม ระเบียงโค้ง ล็อบบี้ สระเก่า การปรับปรุง และภาพอ้างอิงของตอนจบ |
| ทางวิ่งรอบทะเลสาบเมืองทองธานีตอนค่ำ | ตำนานในย่าน เสียง แสง และมุมกล้อง |
| ตึกคอนโดรอบทะเลสาบที่เคยสร้างค้าง และศูนย์แสดงสินค้า | ยุคฟองสบู่ ทิดคำ และบรรยากาศวันมีงานใหญ่ |
| ท่าน้ำปากเกร็ด ศาลเจ้า และบ้านเก่าริมเจ้าพระยา | บ้านใหญ่ของตระกูล เง็ก มั่น และจุดถ่วงหม้อดิน |
| โรงสีเก่าริมเจ้าพระยาที่ยังเหลือในนนทบุรีหรือปทุมธานี | โรงสีไฟนิรันดร์ ปล่อง เสาไม้ และยุ้งฉาง |
| ศูนย์ประวัติศาสตร์เยาวราช (วัดไตรมิตร) | อาเฮง กุลีจีน โพยก๊วน |
| ศาลเจ้าในปากเกร็ดช่วงสารทจีน | ทิ้งกระจาด ฉากสุดท้าย |
| ศาลหลักเมือง | ตำนานอิน จัน มั่น คง |
| ตลาดพระท่าพระจันทร์ | น้องฟ้า คุณวิชัย |
| หอจดหมายเหตุแห่งชาติ / หอสมุดแห่งชาติ | ภาพทุ่งปากเกร็ดก่อนมีเมือง และหนังสือพิมพ์ยุค 2538, 2540, 2541, 2543 |

## 14. คำถามที่ยังเปิดอยู่

1. **ตรวจข้อเท็จจริง:** ปีสร้างและปีเปิดโรงแรมเดิม (แหล่งข่าวบอกต่างกัน ราว 2530 ถึง 2536), ปีปิด (ใช้ 28 ธ.ค. 2552), จำนวนห้อง, ปีขุดทะเลสาบ, สนามแข่งเอเชียนเกมส์ 2541 ในเมืองทองธานี, น้ำท่วมนนทบุรีปี 2538, ใหลตายของแรงงานไทยในสิงคโปร์ช่วงปลาย 2530s, และมีข่าวลือผีแม่ม่ายซ้ำในแคมป์คนงานหรือไม่ (กระแสหลักคือราว 2533 เกมใช้เป็นข่าวลือที่กลับมาอีกครั้ง)
2. **ล้อเรื่องจริง:** ธาม ตระกูล เมือง และการปรับปรุงตึก ล้อมาจากเมืองใหม่ริมทะเลสาบที่มีอยู่จริงในนนทบุรี และบทความเรื่องการเปลี่ยนโรงแรมร้างเป็นคอมมูนิตี้ ในเนื้อเรื่องใช้ชื่อเมืองสมมติ "นิรันดร์ธานี" และย่านสมมติ "บางแกลบ" ชื่อจริงใช้ได้เฉพาะในแผนลงพื้นที่ (หัวข้อ 13) ชื่อคน ชื่อโรงแรม ชื่อคอมมูนิตี้ และชื่อร้านต้องเป็นของสมมติทั้งหมด และต้องต่างจากของจริงพอ เพราะคนจริงยังมีชีวิตอยู่ และเรื่องในเกมมีการฝังคนทั้งเป็นกับไสยศาสตร์ในตระกูล ควรเขียนให้ธามเป็นตัวละครที่น่าเห็นใจ และไม่ใช้ชื่อ โลโก้ หรือป้ายของโรงแรมกับคอมมูนิตี้จริงในงานภาพ ถ้าจะเผยแพร่ ควรปรับรายละเอียดภาพไม่ให้เหมือนอาคารจริงทุกจุด
3. **ภาษา:** บทพูดจีนแต้จิ๋ว อีสาน และไทยสำเนียงจีน ต้องให้เจ้าของภาษาตรวจ ระวังไม่ให้กลายเป็นการล้อสำเนียง
4. **ช่วงเล่นเป็นต้น:** เก็บไว้เป็นช่วงสั้นในองก์ 3 หรือตัดออกเพราะต้นเป็นตัวละครสมทบแล้ว?
5. **ข้าวหอม:** ปรากฏแค่วันหยุดและในฉากสำคัญ หรือมีบทบาทมากกว่านั้น เช่น เป็นเพื่อนเล่นของน้องฟ้า?
6. **อาจารย์ดำ:** เป็นบอสเฟสที่ 4 เต็มรูปแบบ หรือเป็นคัตซีน?
7. **ความละเอียดอ่อน:** วิญญาณเด็ก (น้องฟ้า) ความตายของแรงงาน และการพาดพิงสถานที่จริง ต้องเล่าอย่างให้เกียรติ ไม่พาดพิงวัด บุคคล บริษัท หรือร้านค้าจริง
